# Astryx Engine Documentation

**Latest Updated Version is v0.3**

Welcome to the Astryx Engine Documentation! 

This is an overview of the documentation, and how to navigate it. 

**BUILDING.md:**
This is a guide on how to build. Put simply, we use CMake as our build system. Its easy enough for me to use so it works :).

**CODING_STANDARDS.md:**
Standards for coding that I use so that my codebase becomes readable enough and easy to develop.

**TESTING.md:**
A guide on how to test. It uses ctest, so you just need to run the ctest command in the build/ directory.

**engine/ Directory:**
This is a guide on how the engine actually functions. Explains things like the architecture, etc.

**api/ Directory:**
This is a guide on the engine API for the sandbox, and also how to use the UI. Its very simple, so its not as expansive as the engine directory.
